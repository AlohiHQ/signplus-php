# AnnotationText

Text annotation (null if annotation is not a text)

**Properties**

| Name | Type | Required | Description |
| :-------- | :----------| :----------| :----------|
    | size | float | ❌ | Font size of the text in pt |
    | color | float | ❌ | Text color in 32bit representation |
    | value | string | ❌ | Text content of the annotation |
    | tooltip | string | ❌ | Tooltip of the annotation |
    | dynamic_field_name | string | ❌ | Name of the dynamic field |
    | font | [AnnotationFont](AnnotationFont.md) | ❌ |  |
